# Belle Ju Salão de Beleza — "A cor da Ju"

Next.js (App Router, export estático) + TypeScript + Tailwind + GSAP/ScrollTrigger + Lenis.

```bash
npm install
npm run dev            # desenvolvimento
npm run build          # gera /out (estático)
npm run test:contrast  # AA nas 12 cores + badge de horário em America/Sao_Paulo
```

- Conteúdo e pendências: `content/site.ts` · `docs/A-CONFIRMAR.md`
- Conceito: `docs/CONCEITO.md` · Ensaio: `docs/SHOT-LIST.md` · Screenshots: `docs/screenshots/`
- Domínio: defina `NEXT_PUBLIC_SITE_URL` no build.
